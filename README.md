# NLP README



What started as a side project, a pursuit of automating the news about buzzing stocks and recommendations to segregate the stocks for investment and improved decision making lead me to World of Natural language.
Extracting knowledge from textual data is a kind of data mining process itself.
All of the new cutting edeg techs like gpt, claude, Gemini are based on this.

## Objective:- To segregate stocks from the news and perform basic technical and fundamental analysis.

* Basic TF-IDF lead to successfull classification of news category.
* Performed Entity recognition to fetch stocks name using spacy and NLTK.
  
DB:- 
Model couldn't distinguish between Stock name and Person Name.
* Used word2vec to capture the semantic meaning of the words.
DB:-
* Model was still not able to capture the core essence of sentences and paragraph
* Used Advanced semantic models like LSTm to capture the semantic meaning of the sentences.

Libraries used:-
* Spacy, NLTK, Word2vec
